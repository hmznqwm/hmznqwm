## 🚀 Fitur Utama
- **Desain Poster Ilustrasi & IT Modern**: Mengadaptasi tipografi stensil retro-modern dengan palet warna navy, coral, dan teal yang unik.
- **Kustomisasi Profil Real-Time**: Modal pengeditan nama, bio, data pendidikan, dan tautan sosial secara langsung yang tersimpan di LocalStorage.
- **Mode Dual (Developer & Ilustrator)**: Beralih seketika antara toolset IT/Software Engineering (VS Code, Figma, Git, Postman, Docker, Flutter, Arduino, Android Studio) dan Software Ilustrasi/Desain (Procreate, InDesign, Photoshop, Illustrator, Premiere, dll).
- **Siap Cetak / Ekspor PDF**: Dilengkapi tombol cetak dan style `@media print` yang presisi untuk format dokumen A4.


## 🛠️ Tech Stack & Tools
- **HTML5 & Vanilla JavaScript**
- **Tailwind CSS (CDN)**
- **Google Fonts (Inter, Anton, Space Grotesk)**
- **SVG Vector Graphics**
